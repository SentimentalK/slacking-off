# 地图文件

地图是纯文本，换地图不用改代码：`loo-server --map maps/default.txt`。

## 格式

第一行起可以写 `#` 开头的注释；遇到 `grid` 这一行之后，接下来每一行就是地图的一行格子，直到文件结束。宽度由第一行决定，所有行必须等宽。

```
# comment
grid
..::E::..
..:::::..
.........
```

| 字符 | 含义 |
|---|---|
| `.` | 可建地面 |
| `:` | 禁建地面（入口周围、主走廊） |
| `E` | 入口，同时是禁建地面；全图必须恰好一个 |
| `#` | 墙 |
| `+` | 关着的门 |
| `'` | 开着的门 |
| `1`～`5` | 该等级的马桶 |
| `x` | 未完工/拆除中的工地：墙工地、门工地挡路；马桶工地不挡路 |
| `q` | 主排队道；禁建地面，视图里仍显示为 `:` |
| `r` | 溢出排队道；禁建地面，视图里仍显示为 `:` |

一格至多一个物件。Agent 不写在地图里。

## 排队区

每张地图都必须有排队区，而且必须能排出唯一的先后顺序：

- 主道（`q`）必须非空，并且恰好有一个 `q` 格与入口正交相邻，这格是主道道口（队首）。
- 溢出道（`r`）可以为空。非空时，离入口曼哈顿距离最近的唯一 `r` 格是溢出道道口；并列最近会报错。
- 两条道各自从道口出发、只经过本道格子做 BFS，按距离从近到远排成队首→队尾。同一距离上出现两个格子就无法决定先后，会报错。
- 两条道都存在时必须互相连通（溢出道要能挤进主道）。

排队格在 `loo look`/`loo map` 里显示为 `:`，所以地图观感与旧的禁建地面一致。

## default.txt

- 130 × 100。
- 入口 `(31,50)`，在场内主走廊的左端。
- 主排队道 `y = 50`、`x = 6..30`，共 25 格，道口 `(30,50)` 紧贴入口。
- 溢出排队道 `y = 51`、`x = 6..30`，共 25 格，道口 `(30,51)`；`(31,51)` 是墙，所以溢出道不能直接走进入口，只能打晕挡路者后交换位置挤进主道。
- 新增的 `x = 0..30` 区域除这两行外全部是墙。
- 场内部分沿用旧的 100 × 100 地图整体右移 30 列：十字形主走廊 `y = 48..52` 与 `x = 78..82`，全部禁建。
- 入口附近八间厕所：六间 1 级、两间 2 级，每间是 3×3 的墙门结构，门朝北（朝走廊）关闭。
- 生成方式：`.conductor/gen_map.py`（一次性脚本，不进仓库）；地图本身是唯一依据。
