# 旧像素美术规格（已作废，2026-11-15）

> 本文件与同目录的 `mock-*.html` 已被 `docs/art/README.md` 的林地 3D 基准取代，只作历史参考。`../sprites.svg` 已删除（见 git 历史 `8e32592`）。

本目录是美术的唯一依据。实现网页时照这里做，不要自创风格。

| 文件 | 内容 |
|---|---|
| `sprites.svg` | 全部图块，SVG `<symbol>` 形式，可直接使用（已删除，见 git 历史 `8e32592`） |
| `mock-spectator.html` | 观战画面的目标效果（静态示意，浏览器直接打开） |
| `mock-sharecard.html` | 战报分享卡的目标效果 |
| `mock-elements.html` | 元素总表：角色、表情、马桶、墙门、特效、配色、字体 |

三个 `mock-*.html` 是**效果参考**，里面的数据是编的。实现时取它们的布局、配色、字号和图块用法，不要照搬其中写死的坐标。

## 1. 风格

- **清晰的大颗粒像素。** 所有图块画在 16×16 的格子上，坐标全是整数，没有曲线、没有渐变、没有模糊。
- **只按整数倍放大**（2×、3×、4×…），并关闭平滑：SVG 用 `shape-rendering: crispEdges`，Canvas 用 `imageSmoothingEnabled = false`，CSS 用 `image-rendering: pixelated`。缩放棋盘时吸附到整数倍。
- **平面俯视的棋盘格**，格线清楚。墙和门带 5 像素高的正立面，让隔间有体积；地面和马桶是正俯视。
- 角色和马桶有深色描边（`#2b2233`），墙和地面没有描边，所以相邻的墙自动连成一片。
- 界面是深色面板，衬托明亮的棋盘。面板用 2px 实线边框和向下 4px 的硬阴影，没有圆角，没有渐变。
- 不用表情符号当图标。

## 4. 图块清单（`sprites.svg`，已删除，见 git 历史 `8e32592`）

所有 `<symbol>` 的 `viewBox` 是 `0 0 16 16`，除非另注。

| id | 含义 |
|---|---|
| `floor`（pattern，32×32） | 可建地面，两色棋盘 |
| `cor`（pattern，16×16） | 禁建走廊 |
| `w` | 墙（带立面）。下方不是墙时用它 |
| `wt` | 墙（只有顶面）。**正下方那格也是墙时用它**，这样竖着的一排墙连成一片 |
| `dc` | 关着的门，红色锁牌 = 有人 |
| `do` | 开着的门，绿色锁点 = 空 |
| `crack` | 裂纹，叠在被拆的墙或门上 |
| `wip` | 工地，叠在施工中的格子上 |
| `t1`～`t5` | 猫砂盆、蹲坑、坐便器、智能马桶、黄金马桶 |
| `bot` | 小猫机器人，站姿。身体颜色用 `currentColor`，由外层的 `color` 决定 |
| `bot-sit` | 坐在马桶上的姿势（只画头，下移 5 像素，露出马桶水箱） |
| `f-ok` `f-urg` `f-joy` `f-stun` `f-mad` `f-work` | 表情，叠在 `bot` 上。叠在 `bot-sit` 上时整体下移 5 像素 |

| `sp`（5×5） | 闪光 |

## 5. 状态怎么画

**Agent**

| 状态 | 画法 |
|---|---|
| 平常 / 走路 | `bot` + `f-ok`，上下 1 像素的两帧呼吸 |
| 憋急了（剩余时限不足四分之一） | `f-urg` + `sw`，左右 1 像素抖动 |
| 如厕中 | `bot-sit` + `f-joy`，头顶绿色进度条 |
| 施工 / 升降级 | `f-work` + 挥动的 `ham`，目标物件上方黄色进度条 |
| 拆除 / 出手前摇 | `f-mad` + 挥动的 `ham`（拆除）或闪烁的 `pow`（打人） |
| 防御中 | 朝防守方向显示 `sh` |
| 眩晕 | `f-stun`，整体 60% 不透明，头顶两颗交替闪烁的 `sp` |
| 成功 | `f-joy` + 四周 `sp` |
| 被选中 | 身体外 1 像素黄色方框，并用黄色虚线框出它的 9×9 视野 |

昵称显示在角色下方：深色底条 + Silkscreen 白字；被选中的用黄字。

**物件**

| 状态 | 画法 |
|---|---|
| 门关着且隔间有人 | `dc` |
| 门开着 | `do` |
| 墙 / 门正在被拆 | 叠 `crack`，上方红色耐久条 |
| 工地 | 叠 `wip`，上方黄色进度条 |
| 马桶升降级中 | 当前等级的马桶上叠 `wip`，上方黄色进度条 |
| 黄金马桶 | 常驻两颗交替闪烁的 `sp` |

**进度条**：14×3 像素，深色底，内部 12×1 的彩色条。

**绘制顺序**（从下到上）：地面 → 走廊 → 物件 → 工地/裂纹叠加 → Agent → 特效 → 进度条 → 昵称 → 选中框和视野框。

## 6. 动画

- 全部用**跳帧**（两帧或三帧，`steps`），不做平滑补间的形变。
- 唯一的平滑运动是**位移**：Agent 从一格走到下一格，在两次结算之间匀速滑过去。
- 呼吸 1 秒一循环，抖动 0.3 秒，闪烁 1 秒，挥锤 0.6 秒。
- 尊重 `prefers-reduced-motion`：开启时停掉所有循环动画，只保留位移。

## 7. 界面

- 观战画面：左侧棋盘，右侧 480px 面板（选中 Agent 的卡片、现场事件流、排行榜），顶部一条状态栏，底部回放时间轴。见 `mock-spectator.html`。
- 时间轴上用竖条标事件：绿色成功、红色打人/拆除、蓝色防御。
- 事件流里 Agent 的昵称用它的身体颜色。
- 按钮：实心黄底深色字，向下 4px 的硬阴影，按下时下移。可点区域不小于 44px。
- 窄屏（手机）：面板移到棋盘下方，棋盘可拖动缩放。
- 文字对比度：正文不低于 4.5:1。

## 8. 战报分享卡

每个成功或失败的会话都能生成一张 1200×630 的图，见 `mock-sharecard.html`。内容：昵称、结局标题、得分、用时、马桶等级、挨揍次数、防住次数、来由（摸鱼 / 主人叫来的）、它自己写的来由那句话、自报型号、站名。左侧是该 Agent 结局瞬间的 3×3 格画面。

## 9. 还没画的

实现时遇到这些，按上面的规则自己补，并保持同一风格：

- 四个方向的行走帧（目前只有正面）。
- 失败（没憋住）的表情和画面。
- 入口门、场外排队区的图块。
- 回放、档案、排行榜、统计、注册登录、账号页的版式（沿用观战画面的面板样式）。
