# 美术基准：林地 3D

本目录是画面与界面的依据。2026-11-15 起以 `prototype/` 里用户认可的林地原型为准；旧的像素规格已作废，移到 `legacy/`。

| 文件 | 内容 |
|---|---|
| `prototype/forest.html` | 带界面的原型（three.js r128，几何体全部代码生成；数字是示例数据，交互接的是假状态） |
| `prototype/forest-noui.html` | 同一场景去掉界面，用于对照渲染 |
| `prototype/forest.png`、`forest-dusk.png`、`forest-zoom.png` | 原型画面：白天、黄昏、近景 |
| `prototype/ui-watch.png`、`ui-play.png`、`ui-board.png`、`ui-account.png` | 原型界面：观战、上场、排行榜窗口、账号窗口 |
| `legacy/` | 作废的像素规格与 `mock-*.html`，只作历史参考 |
| `sprites.svg` | 旧像素图块；只剩 `/replay` 旧页面在用，随它删除 |

原型是基准，不是要照搬的代码。正式实现在 `web/src/world3d/`（场景）与 `web/src/shell/`（界面）。

## 1. 画风

- 暗沉的橄榄绿与棕色，强暖色斜光与长影；全屏四角压暗（暗角）。
- 层叠锯齿松树围成林中空地：地图外圈的墙画成密林，林缘参差，不排成直线；场内零星中大松树。
- 立体草、平整土路（禁建走廊）、破旧营地道具（桶、木箱、石头、沙袋）。
- 厕所是 3×3 木板棚屋：四根角柱、四面各自是墙 / 门 / 工地 / 空，四面齐全时盖波纹铁皮屋顶；屋脊挂等级牌（1–5 个金点，5 级整块金色），每扇门的那面屋檐上立小旗（开 = 绿、关 = 红），屋脊上一盏占用灯。
- 角色是原创的鸭形双足机器人：彩色外壳（12 色调色板）、外露舵机关节、圆环镜头、扁嘴、领带。走路不左右摇晃。
- 状态贴片（被中断的感叹号、汗滴、眩晕星星、如厕进度环）在远景下随镜头距离放大，最多 2.6 倍。

## 2. 光照与颜色

数值照原型（`prototype/forest-noui.html` 第 52–64、292–320 行）：

| 项 | 白天 | 黄昏（k = 1） |
|---|---|---|
| 太阳色 / 强度 | `#ffdfae` / 2.6 | `#ff7a3a` / 0.85 |
| 太阳方向（相对场地中心） | (−12, 13, 5) | (−18, 5, 5) |
| 半球光天空色 / 强度 | `#a9c4ff` / 0.42 | `#4a50a8` / 0.28 |
| 半球光地面色 | `#2f3d1c`（按线性值） | 同左 |
| 色调映射 | ACES Filmic，曝光 1.12 | 同左 |

- three r155 以后光强按物理单位，原型的强度在实现里乘 π。
- 颜色空间：原型在 r128 下对材质色、灯光色显式调用 `convertSRGBToLinear()`；r186 的 ColorManagement 已自动把十六进制颜色当 sRGB 转换，所以实现里**不再**调用它。原型没转换的颜色（半球光地面色、背景色）在实现里要按线性值设，才和原型一致。验证记录：`.conductor/l34/colorcheck/`（正确移植后白天与 r128 平均绝对差 2.3 / 255）。
- 黄昏灯光：原型用 r128 的点光源（旧衰减公式 `(1 − d/distance)^decay`，光圈大而亮）。实现不用点光源（十几盏点光源让黄昏掉到 5 fps），而是按同一公式在 CPU 上把灯柱灯（`#ffa850`，距离 7）与棚屋灯（`#ffb060` 按线性值，距离 5）烘成一张覆盖地图的照度贴图（再乘灯到地面的入射余弦，有下限），在着色器里加到漫反射光照上；强度以 `decor.ts`、`objects.ts` 顶部常量为准（看图复核后从原型的 3 / 2.2 调到 2.4 / 1.8）（`web/src/world3d/lamplight.ts`、`vision.ts`）。

材质色（`web/src/world3d/materials.ts`）：木板 `#7a583a` `#6c4d33` `#846040` `#72533a`，深木 `#4a3526`，树皮 `#3a2a1e`，松针 `#35501f` `#41612a` `#4f7431` `#5f8839` `#73a043`。

## 3. 界面

- 3D 画面铺满视口，其余都是浮层（`web/src/shell/ui.css`，样式取自 `prototype/forest.html` 第 7–55 行）。
- 顶部：左上标题与 LIVE/回放、TICK、下次结算倒计时；居中三种模式（观战 / 我自己上 / 回放）；右上在场与排队人数、排行榜 / 统计 / 账号 / 设置。右侧选中角色的卡片（未选中时是前三名），左侧现场事件流，底部一条随模式变化。
- 排行榜、统计、账号、档案、登录、注册、设置是窗口：深色半透明面板、圆角 14px、背景模糊；旧路径是深链。
- 颜色变量：金 `#ffcf40`、面板 `rgba(16,20,18,.74)`、描边 `rgba(255,255,255,.14)`、次要文字 `#b9c2b4`、成功 `#4cc964`、失败 `#f0554d`、蓝 `#58b7ff`。
- 字体：Noto Sans SC 400/700/900（`@fontsource`，自托管，按 unicode-range 分片加载）；数字与命令用系统等宽字体。不请求外部域名。
- 窄屏（≤ 700px）：模式切换占满第二行，事件流收成一行，卡片收成一行摘要可展开，窗口全屏；无横向滚动。

## 4. 画质档位

| 档 | 阴影 | 立体草 | 像素比 | 抗锯齿 |
|---|---|---|---|---|
| 高 | 2048 | 有 | ≤ 2 | 有 |
| 中 | 1024 | 无 | 1 | 有 |
| 低 | 无 | 无 | 1 | 无 |

低档另外把地面贴图降到 24 px/格、外围松树密度减半。

自动：软件渲染、宽 < 700 或 `hardwareConcurrency ≤ 4` 用低；其余从高开始，开局 3–6 秒帧时中位 > 25 ms 降一档，最多降到低，不升回。设置窗口与 `?quality=` 可手选。
