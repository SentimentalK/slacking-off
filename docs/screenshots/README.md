# 页面截图

这里是用**真实 Chrome**（puppeteer-core + headless Google Chrome）对着 official 模式的本地服务端生成的页面截图，不是设计稿。服务端参数：`--official --tick-seconds 2 --map maps/default.txt`；账号 `w2-human` 的人类角色 `w2-player`（颜色 3）已入场，站在入口 `(6,15)`；页面轮询 `GET /api/play/state`。

## play-1440.png

- 视口 1440×900，路由 `/play`，桌面两栏：左侧棋盘，右侧状态 / 选中格 / 自己的事件。
- 棋盘为服务端返回的 9×9 窗口（原点 `(2,11)`），zoom 3（432×432）。
- 截图时 tick = **4**；面板显示需求「便意」、如厕进度 `0/8`、`deadline=55`（还有 51 tick），事件流为自己的两条移动事件。
- 顶部「下一结算」正好落在结算瞬间，显示「结算中」。

## play-390.png

- 视口 390×844，整页截图，同一个会话（tick = **5**）。
- 棋盘 288×288（9×9，zoom 2），控制、状态、事件竖排；页面无水平溢出。
- 「下一结算」显示本地倒计时 `0.8s`；该值每秒递减，并在每次拉取到新 tick 时用服务端的 `ms_to_next_tick` 校正。
